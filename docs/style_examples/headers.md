# Headers Styling

## Markdown Headers
Markdown offers a simple way to create headers. Documentation can be found [here](https://www.markdownguide.org/basic-syntax/#headings).

````
# Header style 1
## Header style 2
### Header style 3
#### Header style 4
##### Header style 5
###### Header style 6
````

Through the [deltares.css](../../assets/stylesheets/deltares.css) stylesheet it 
is possible to style the headers.

Through the [deltares.css](../../assets/stylesheets/deltares.css) stylesheet it is possible to style these headers.

The current styles defined in the deltares.css file are configured according to the Deltares design guidelines.

The entries for the Header styles are can be found in the deltares.css under section:


````
 /* Deltares overrides for Headers */
 
````
