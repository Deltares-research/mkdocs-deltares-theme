# MkDocs

[MkDocs](https://www.mkdocs.org/) is a static site generator that's geared towards building project documentation. 
It takes Markdown files and builds a static HTML website from them.

## Material for MkDocs

[Material for MkDocs](https://squidfunk.github.io/mkdocs-material/) is a theme for MkDocs that provides a modern and responsive design, 
along with many features and customization options. It is widely used in the MkDocs community and is known for its clean and professional look.

## Deltares MkDocs Template

The [Deltares MkDocs Template](https://github.com/Deltares-research/mkdocs-deltares-theme) is an adaptation of the Material for MkDocs theme. It provides stylesheet customizations that 
offer users a simple way to design project documentation that is consistent in look and feel with [Deltares](https://www.deltares.nl/en/).
