# Deltares MkDocs Template

The Deltares MkDocs Template can be found on [GitHub](https://github.com/Deltares-research/mkdocs-deltares-template).

This template is based on the [Material for MkDocs](https://squidfunk.github.io/mkdocs-material/) theme and provides a 
starting point for creating documentation sites with MkDocs.

The purpose of this template is to provide a consistent look and feel for documentation sites created by [Deltares](https://www.deltares.nl/en/), 
by providing some style examples and configurations.
